DroidFlyer is a [bitFlyer Lightning](https://lightning.bitflyer.com) client for Android.

## Quick start

1. Install [DroidFlyer from Google Play](https://play.google.com/store/apps/details?id=com.unhappychoice.droidflyer).
2. Sign in to bitFlyer Lightning and create an API key and secret on the [developer page](https://lightning.bitflyer.com/developer). Give the key permission to retrieve your asset balance so DroidFlyer can verify it.
3. Open DroidFlyer and tap **Setting**. Enter the **API key** and **API secret**, then tap **Apply**. The app shows **Saved API key** when the balance request succeeds.
4. Tap **Order**, then **Limit**, to view the bitFlyer Crypto CFD order book. You can read the bids and asks without placing a trade.
